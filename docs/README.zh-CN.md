# Typecast Studio · 直播花字

[English](../README.md)

**英文安装程序，中文网页编辑器。** 从一条文案开始，选好样式和动画，就能生成透明直播花字。无需另装 Node.js、npm 或开发工具，无需账号。

**[下载 Windows 安装文件](https://github.com/pingulee/typecast-studio/releases/latest)**

## 安装

1. 下载 `Typecast-Studio-Setup-1.3.1.exe`，双击安装。安装步骤全部为英文，没有语言选择弹窗。
2. 使用默认选项即可。默认安装到 `C:\Program Files\Typecast Studio`。
3. 双击桌面上的 **Typecast Studio**，浏览器会打开中文编辑器。

Windows 10/11 64 位。运行环境和字体已包含；托盘使用 Windows 自带的 .NET Framework，正常受支持的 Windows 安装无需另装运行库。独立输出窗口使用 Edge 或 Chrome。安装文件尚未代码签名。

`Start automatically when I sign in` 默认勾选，表示登录后自动运行托盘和后台，不弹出编辑器；不需要时可以取消。

## 一屏完成

1. **直播文案**：默认只有一个空输入框。输入想显示的文字。
2. **+ 添加文案**：需要更多时再加，每次一条，最多 8 条。点垃圾桶可删除多余文案，保留一条也可以。
3. **选择样式**：金色、白色、霓虹、冰蓝、玫瑰金、翡翠绿。
4. **动画效果**：选择入场方式。
5. **文字特效**：无特效、火焰、流光波纹、漂浮光点、动态立体。
6. **打开透明输出 / 复制链接 / 保存图片**：按直播软件支持的方式使用。

默认单条布局针对 1024 × 768 桌面设计，更多文案只在输入列表内滚动。一条文案一直保留，多条会逐条轮播。文案最长 160 字，长句自动缩小到一行。

**冒号右侧和联系方式不会自动换色。** 字体整体遵循所选样式。去掉了描边、发光、对齐、尺寸等复杂调节项。

## 背景始终透明

火焰、波纹、光点和立体效果只出现在文字周围或后方。不会加入绿底、黑底或其他整块背景。预览中的棋盘格仅用来表示透明，不会保存到文件。

- 编辑器：`http://localhost:4318`
- 固定透明输出：`http://localhost:4318/overlay`
- 独立输出页面：`http://localhost:4318/capture`（同样透明）

支持网页源的直播软件可以添加透明链接，实现实时更新。程序与直播软件需在同一台电脑运行。

**普通浏览器窗口捕获不一定保留网页透明度。** 如果抖音直播伴侣没有兼容的网页源，请使用透明 PNG 或当前版本支持的 GIF/WebP 图片素材。动画格式是否支持需在实际伴侣版本确认。文件保存的是当时的效果，不会像链接一样实时更新。程序不会为兼容性自动添加纯色底。

WebP 可保留柔和的半透明边缘；GIF 只有透明/不透明两级，因此火焰和发光边缘可能较硬。PNG 为静态图，GIF/WebP 为动画。选择持续文字特效时，导出动画会循环播放。

## 托盘与退出

任务栏有 Typecast Studio 图标，可能位于隐藏图标箭头中。

- 双击图标或 **Open editor**：打开编辑器。
- **Open output window**：打开透明输出。
- **Quit**：结束后台程序，移除托盘图标。
- 网页右上角 **退出程序**：保存完成后退出后台和托盘。

只关闭浏览器标签页不会停止后台。再次使用时，从桌面打开 Typecast Studio。

## 保存和升级

修改会自动保存到 `%LOCALAPPDATA%\Typecast Studio\settings.json`，不写入 Program Files。输出窗口使用独立浏览器配置，不读取平常浏览器中的账号。

升级前先退出旧程序，再安装新版本。已有文案不会被删除；如果旧版保留了两条，点垃圾桶即可改为一条。旧版联系方式高亮不再生效，界面统一为中文。

Windows 的已安装应用中可以卸载。卸载删除程序、快捷方式和启动项，保留 AppData 中的文案与独立浏览器配置，方便重新安装。

## 开发与验证

普通用户只需安装 EXE。源码构建方法见英文 README。自动检查包括 Windows 实际托盘菜单、单实例启动、文案添加/删除、透明效果、网页退出、托盘退出、重启及卸载。实际抖音素材支持需在直播电脑上确认。

### 动态文字特效

1.3 版重新制作了四种特效：沿字形燃烧的火焰与火星、文字本身的波浪扭动、掠过文字的发光粒子，以及带有实体侧面和流动高光的立体文字。特效持续循环，输出背景始终透明。导出的动图也使用完整循环。只需在原有的特效菜单中选择，无需额外设置。

1.3.1 优化了火焰：向上流动、固定字形发射位置、细长渐隐的火苗与更少的火星。WebP 导出为 30 帧/秒，GIF 为 25 帧/秒。柔和的火焰边缘建议使用透明网页或 WebP；GIF 的透明边缘较硬。
